**Features**
SafeSense is an intelligent, community-based crime reporting and alert application designed to help communities in South Africa share safety information and stay informed.

Authentication & User Accounts:
User registration and login.
Secure account authentication.
Personal profile management.
View and update personal information.

Profile Management:
Display user profile information, including name, username, contact details, and neighbourhood.
View personal crime-report statistics.
Access profile-related settings and app information.

Crime Reporting:
Report crime incidents within the community.
Support community-based crime reporting to improve local awareness.

Map & Location Awareness:
Map-based interface for community safety awareness.
Location-related features to support the reporting and discovery of incidents.

Notifications & Alerts:
Crime alert preferences.
Emergency alert preferences.
Community announcement preferences.
Notification settings management.

Privacy & Safety:
Profile visibility preferences.
Trusted Circle location-sharing preferences.

Emergency Contacts:
Add and manage emergency contacts.
Store contact names, phone numbers, and relationships.
Remove saved emergency contacts.
